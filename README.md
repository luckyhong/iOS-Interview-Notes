# iOS Interview Notes · iOS 面试复习笔记

一份持续更新的 iOS 面试知识库：既保留 Runtime、RunLoop、内存管理、多线程这些经典的"硬核八股"，也补充了 **AI 时代 iOS 工程师会被实际问到的新问题**——怎么和 AI 工具协作、怎么把大模型能力做进 App、以及"AI 会不会取代 iOS 开发"这种面试官越来越爱问的软性问题。

无论你是正在准备面试的候选人，还是在设计面试题的面试官，都可以把这里当一份可以直接查阅的参考资料。所有答案提供的是一种思路参考，不追求"标准答案"式的长篇论证，欢迎指正和提 PR 补充。

## 怎么用这份笔记

- **临阵磨枪**：直接按目录表从上到下过一遍每个模块的问题列表，先看要点，答不上来的再展开看详细解析。
- **系统复习**：建议顺序是"语言与底层原理 → 内存并发性能 → 架构算法 → AI 时代新增内容"，最后再补一遍经典合集里覆盖到、但前面没提到的题目。
- **面试官选题**：可以直接从每个模块里挑题目，也可以参考 AI 时代模块里"考察点"那一列，判断某道题是想看候选人的技术深度还是判断力。

## 贡献指南

欢迎通过 PR 补充新问题、修正现有答案里的错误，或者针对某个答案继续深入解析。提交时请：

1. 保持现有的文档格式：`### 序号. 问题` 作为标题，先给可以直接记住的要点，再展开说明，涉及代码的补一段可运行示例；
2. 新增独立主题时，优先在已有目录下新建 Markdown 文件，并同步更新本 README 的目录导航；
3. 涉及较新的系统 API（尤其是 AI 相关能力）时，注明适用的最低系统版本，避免读者踩版本兼容的坑。
